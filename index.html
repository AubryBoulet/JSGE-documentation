🎮 JSGE

Just a Simple Game Engine: a lightweight 2D game engine written in pure JavaScript (ES6+), with zero dependencies. Designed for rapid game prototyping with advanced visual effects.

It’s a good fit for prototyping game mechanics, learning game development, personal projects or small HTML5 games, and experimenting with Canvas and animations.

Source code on GitHub

Features

🎇 Particle system

Fire, smoke, explosions, with precise control over speed, color and lifetime.

💡 Light engine

Basic mask-based lighting. No true shadow casting yet: a raycasting-based system is planned.

📹 Nested cameras

Parallax and filter effects with child cameras. The parent camera takes care of clearing their content.

🎭 Scene management

Optimized element organization with automatic z-order sorting.

🎨 Animated backgrounds

Parallax, loops and velocity for dynamic backgrounds.

🔄 Smooth transitions

A large library of easing functions.

🎮 Entity system

Game object management: position, physics and collisions.

Installation

The quickest way is to import JSGE from the jsDelivr CDN, in an ES module.


<canvas id="gameCanvas" width="800" height="600"></canvas>
<script type="module">
  import { Camera, Scene, ParticleEmitter } from "https://cdn.jsdelivr.net/gh/AubryBoulet/JSGE@main/JSGE/jsge.js";

  const camera = new Camera({
    canvas: document.getElementById("gameCanvas"),
    position: { x: 0, y: 0 },
    dimensions: { width: 800, height: 600 },
    backgroundColor: "#166088"
  });
</script>

For development, clone the repository (git clone https://github.com/AubryBoulet/JSGE.git) and import from JSGE/jsge.js, the entry point that re-exports every class:

CameraSceneEntitySpriteTextButtonElementTransitionParticleEmitter

Try it: a campfire

Move the mouse over the canvas: the fire follows it. Edit the code, then click “Run”. The engine is loaded live from the CDN.

Best practices

✅ Do

  • Always use a Scene: scene.draw(camera) followed by camera.flipBuffer() is mandatory.
  • Call flipBuffer() manually: nothing is displayed without it.
  • Call camera.clear() every frame to avoid visual artifacts.
  • Limit the number of light emitters: the light engine uses several canvases.

❌ Avoid

  • Private methods (starting with _ or #): incorrect use can crash the engine.
  • Drawing without a Scene: entities and elements have no draw function of their own.
  • Using moveCamera() for scrolling: it moves the camera and its content, it is not a scrolling solution.
