Scene

A scene holds the elements of your game and keeps them sorted by depth. It is the recommended way to draw anything.

Usage


import { Scene } from "https://cdn.jsdelivr.net/gh/AubryBoulet/JSGE@main/JSGE/jsge.js";

const scene = new Scene();
scene.add(player);            // z-order 0
scene.add(explosion, 1);      // drawn on top of z-order 0
scene.addArray(blocks);       // several elements at once

function mainLoop() {
  cam.clear();
  scene.draw(cam);            // queue the whole scene on the camera
  cam.flipBuffer();           // mandatory: renders the frame
  requestAnimationFrame(mainLoop);
}

A scene can contain entities, elements and particle emitters. Elements with a higher zOrder are drawn on top of the others; elements sharing the same zOrder are drawn in the order they were added. The sorting is done when elements are added or re-ordered, not on every frame, which is why a scene performs better than drawing entities one by one with entity.draw(cam).

Methods

MethodDescription
add(element, zOrder = 0)Adds an element to the scene.
addArray(elements, zOrder = 0)Adds every element of an array (an error is thrown if it is not an array).
remove(element)Removes an element from the scene.
zOrder(element, zOrder)Changes the z-order of an element already in the scene and re-sorts the scene.
draw(camera)Queues the scene on a camera for the current frame. Call it every frame, between clear() and flipBuffer(). The same scene can be drawn on several cameras.

Element instances added to a scene are also registered as displayed elements, which entities with gravity use as ground. This is covered on the Element page.
