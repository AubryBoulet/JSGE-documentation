Sprite

A sprite is the image of a game object. It can be loaded from a file, or drawn by code on its own canvas.

Drawing a sprite by code

Sprite.create(width, height) returns an empty sprite backed by its own canvas. Draw on it with sprite.ctx, using the usual Canvas 2D methods, then give it to entities or elements. No image file is needed.


const ball = Sprite.create(10, 10);
ball.ctx.fillStyle = "white";
ball.ctx.arc(5, 5, 5, 0, 2 * Math.PI);
ball.ctx.fill();

const player = Entity.create({ sprite: ball, position: { x: 100, y: 100 } });

Loading an image

Sprite.load(imageSrc, animate) is asynchronous: it returns a promise that resolves with the sprite once the image has loaded, and rejects if it fails.


const hero = await Sprite.load("images/hero.png");

Static methods

MethodDescription
Sprite.create(width, height, animate)Creates a sprite drawn by code, with its own canvas.
Sprite.load(imageSrc, animate)Loads an image file. Returns a promise.

The animate argument turns the sprite into an animated sprite sheet. See the Animation page.

Properties

NameDescription
imageThe underlying image or canvas.
ctxRead-only 2D context, only for sprites made with Sprite.create().
width, heightSize of the sprite in pixels (before the entity’s scale is applied).
imageLoadedBoolean, true once the image is ready.
animate, animationsWhether the sprite is animated, and its animation settings.
