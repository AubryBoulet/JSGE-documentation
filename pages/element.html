Element

An element is a static piece of scenery: a sprite with a position and a scale. It is lighter than an Entity because it has no velocity and no collision detection.

Creating an element


const platform = Element.create({
  sprite: platformSprite,
  position: { x: 200, y: 400 },
  scale: 2
});
scene.add(platform);

An element is drawn through a Scene. It never moves or updates by itself: change position from your own code (for instance in camera.onUpdate) if you want it to move. It cannot use an animated sprite (an error is thrown).

Element.create(data, assigns) accepts, like entities, an array of objects whose properties and methods are copied onto the element, and element.assign(objects, { overwrite }) does the same later.

Properties

NameDefaultDescription
sprite–The Sprite to draw.
position{x:0, y:0}Top-left corner of the element.
scale1Size multiplier of the sprite.
flippedX, flippedY–Booleans: mirror the element horizontally or vertically.
onGravityContact–Function called as onGravityContact(element, entity) on every frame an entity affected by gravity stands on the element. Elements added to a scene are registered as ground for those entities.

Try it

Clouds are elements. They have no velocity, so the code moves them manually in onUpdate.
