Light engine

A basic mask-based lighting system, managed directly by the camera. It darkens the whole view, then cuts light-shaped holes in the darkness.

This is a lightweight effect: there is no shadow casting yet (a raycasting-based system is planned). The light engine uses several canvases, so keep the number of lights reasonable.

Enabling lights

The light engine is created by the camera. camera.initMaskLightEngine() builds a mask the size of the camera and returns the engine. The camera then renders the lights on every frame, after the scene and before postProcess. The engine and light classes are not exported by jsge.js: you only use the objects returned by these calls.


const lights = cam.initMaskLightEngine();
lights.mask = { color: "rgba(0, 0, 0, 0.9)" };      // darkness level

const torch = lights.addLightEmitter(500, 300, 120, "rgba(255, 170, 60, 0.25)");
torch.x = 520;                                       // lights can move

The mask is black and opaque by default. Lower its alpha to let part of the scene show through the darkness. Light positions are in camera coordinates.

Drawing above the lights

By default everything is drawn below the darkness. To keep some elements bright (a lamp, a HUD, a character carrying a torch…), give the light engine a zOrder and add those elements with a higher one:


lights.zOrder = 9;
scene.add(tile);          // zOrder 0: under the darkness
scene.add(lamp, 20);      // zOrder 20: drawn above the mask and the lights

Light engine

MemberDescription
addLightEmitter(x, y, radius, color = null)Creates a light and returns it. color is an optional CSS color used to tint the lit area, give it some transparency.
removeLightEmitter(emitter)Removes a light.
getLightEmitters()Returns the array of lights.
maskSetter taking an object with any of x, y, width, height and color (the mask color, including its transparency). Omitted or zero values keep their current value.
zOrderDepth of the light layer. Elements drawn with a higher zOrder (scene.add(element, zOrder) or draw(camera, zOrder)) are drawn above the mask and the lights, the others below. Assign it explicitly, see below.
getRenderCtx()The 2D context of the canvas the lights are composed on.

Light emitter

PropertyDescription
x, yCenter of the light.
radiusRadius of the lit area, in pixels.
colorTint color of the lit area (CSS color).
angleRangeOpening of the light in degrees. 360 (default) is a full circle, a smaller value makes a cone.
lookAtFor cones: the {x, y} point the cone faces (it cannot be {x: 0, y: 0}). The direction is computed when lookAt is set, so set it again after moving the light. Read the resulting angle, in radians, with lineAngle.

A light also has a method to shade its tint with a radial gradient:

MethodDescription
createGradient(r0, r1, stops)Sets the tint of the light to a radial gradient centered on it. r0 and r1 are the inner and outer radii in pixels, and stops is an array of [offset, color] pairs, with an offset between 0 and 1.

torch.createGradient(0, 130, [
  [0, "rgba(255, 200, 100, 0.5)"],
  [1, "rgba(255, 200, 100, 0)"]
]);
