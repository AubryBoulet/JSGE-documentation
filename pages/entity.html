Entity

An entity is a game object: a sprite with a position, a scale, a velocity and optional collision detection.

Creating an entity


const player = Entity.create({
  sprite: playerSprite,
  position: { x: 100, y: 200 },
  scale: 2,
  physic: true,
  velocity: { x: 1, y: 0 }
});
OptionDefaultDescription
sprite–The Sprite to draw. A sprite can be shared by many entities.
position{x:0, y:0}Top-left corner of the entity.
scale1Size multiplier of the sprite.
physicfalseWhen true, the entity checks the collisions you registered on it.
velocity{x:0, y:0}Pixels added to the position on every frame the entity is updated.
gravity0Maximum falling speed in pixels per frame. 0 disables gravity. See Gravity.
gravityAcceleration1Speed gained by a falling entity on every frame, in pixels per frame.

Entity.create(data, assigns) also accepts an array of objects as second argument. Their properties and methods are copied onto the entity (hit points, a takeDamage() function…). An existing property is never overwritten, a warning is logged instead. entity.assign(assigns, { overwrite: true }) does the same later and can overwrite.


const block = Entity.create({ sprite }, [{
  life: 3,
  takeDamage(damage) { this.life -= damage; }
}]);

Drawing and updating

Add the entity to a Scene (recommended), or call entity.draw(camera, zOrder = 0) every frame to queue it directly on a camera (the z-order is then recomputed each frame). By default an entity updates itself (position, collisions) every time it is drawn on a new frame. Set autoUpdate = false to call entity.update() yourself.

Collisions

Collisions are declared on the active entity, which must have physic: true. The callback receives the entity that was hit, and is called on every update while the two overlap. The hit box is the sprite size multiplied by the scale. (Note the spelling of the API: addColision…, with a single “l”.)


player.addColisionWithEntity(wall, (wall) => { /* … */ });
player.addColisionWithArrayOfEntities(coins, (coin) => {
  scene.remove(coin);
  player.removeColisionWithEntity(coin);   // stop checking this one
});

Methods

MethodDescription
Entity.create(data, assigns)Static. Creates an entity, optionally with extra properties.
draw(camera, zOrder = 0)Queues the entity on a camera for the current frame.
update()Applies velocity and checks collisions. Called automatically while autoUpdate is on.
addColisionWithEntity(entity, callback)Registers a collision with one entity.
addColisionWithArrayOfEntities(entities, callback)Registers the same callback for every entity of an array.
removeColisionWithEntity(entity)Unregisters a collision.
assign(objects, { overwrite = false })Copies the properties of the given objects onto the entity.

Properties

NameDescription
sprite, position, scaleThe sprite, the top-left position {x, y} and the size multiplier.
velocity{x, y} in pixels per frame. You can edit its fields directly (entity.velocity.x *= -1 to bounce).
physicEnables collision checks.
physicsThe list of registered collisions, as {entity, onCollision} objects.
flippedX, flippedYBooleans: mirror the entity horizontally or vertically.
currentAnimationFor animated sprites: write the name of an animation (a string). Reading returns the running animation state. It must be set before the first update. See Animation.
frameRateWrite-only. Number of game frames each picture of the current animation stays on screen.
gravity, gravityAccelerationSee Gravity.
autoUpdateBoolean (true by default): update the entity whenever it is drawn.

Animation

An entity whose sprite is a sprite sheet plays an animation chosen with entity.currentAnimation = "name". Everything about sprite sheets is on the Animation page. The hit box used for collisions then comes from the current animation.

Gravity

Experimental. The gravity system is a first draft that will be reworked: expect changes in a future version.

With gravity above 0, an entity falls: its speed grows by gravityAcceleration pixels on every frame, up to gravity. It stops when the bottom of its hit box reaches the top of an Element displayed through a scene and overlapping it horizontally. Only the top of elements is solid, and gravity requires an animated sprite, since the hit box comes from the animation.

While an entity stands on an element, that element’s onGravityContact(element, entity) function is called on every frame. To jump, assign a new upward velocity object: gravity gradually cancels it, then the entity falls back.


const player = Entity.create({ sprite: sheet, position: { x: 100, y: 0 }, gravity: 12, gravityAcceleration: 0.5 });
player.currentAnimation = "idle";

platform.onGravityContact = (platform, entity) => { grounded = true; };
if (grounded) player.velocity = { x: 0, y: -20 };   // jump
