Text

Renders text on its own canvas, with automatic line wrapping and per-word effects: colors, wave, shake, blink and gradients.

Usage

A Text is not an entity: it owns a canvas that you draw on the camera yourself. The best place is camera.postProcess, which draws on top of everything. Call text._update() on every frame so animated effects advance.


const score = new Text("${white Score: 0}", 300, 50);   // value, width, height

cam.postProcess = () => {
  score._update();                                      // advances the effects
  cam.cameraCtx.drawImage(score.canvas, 10, 10);
};

score.value = "${wave(5,2,5,1.5) ${white Score: 10}}";   // changes the text

Text is black by default. Color it with the markup below. Words are wrapped to the width given to the constructor.

Effect markup

An effect applies to words: ${effect words}, where ${ must be glued to the effect name, followed by a space, and the effect ends with the closing }. Effects can be nested.

MarkupResult
${red Hello}, ${#4cc9f0 Hello}Colors the words. Use a CSS color name or a hex color.
${wave Hello}Letters move up and down in a wave.
${shake Hello}Words shake randomly.
${blink Hello}Words blink.
${grad(name) Hello}Fills the words with a gradient registered with text.addGradient(name, gradient).

Wave, shake and blink accept parameters in parentheses, in this order: amplitude (pixels, default 5), frequency (frames between two updates, default 9), speed (default 3), duration (seconds, default 0 = endless). For example ${wave(5,2,5,1.5) …} is a wave of 5 pixels, updated every 2 frames, at speed 5, lasting 1.5 seconds. Amplitude only applies to wave and shake, so for blink use ${blink(0,20) …} to set the frequency.

The markup contains ${, which JavaScript treats as an interpolation inside backtick template strings. Write effect strings with regular quotes, or escape the dollar sign (\${).

Properties and methods

NameDescription
new Text(value, width, height)Creates the text and its canvas.
valueThe text. Setting it parses the effect markup again. Reading it returns the text without markup.
fontCSS font, "24px arial" by default.
textAlign"start" (default), "end", "left", "right" or "center".
textBaseline, textDirectionSame as the Canvas properties.
width, heightSize of the text canvas.
amplitude, frequency, speed, durationDefault parameters used by effects that do not specify their own.
canvas, ctxThe text canvas and its 2D context. Draw canvas on the camera with drawImage().
effectsRead-only boolean: true if the text contains effects.
addGradient(name, gradient)Registers a gradient for the grad effect.
_update()Advances the effects and redraws the canvas when needed. Call it on every frame if the text has effects.
