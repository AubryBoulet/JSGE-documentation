ParticleEmitter

Emits particles for effects such as fire, smoke, impacts or explosions, with control over speed, color, size and lifetime.

Usage


const fire = new ParticleEmitter(400, 500);       // x, y
fire.particleColorRange = { startColor: "#ff4400", endColor: "#ffff00" };
fire.particleLifetime = { min: 500, max: 1500 };
fire.emissionDuration = 0;                         // 0 = unlimited
fire.startEmission();

scene.add(fire, 1);       // drawn above z-order 0
// or, without a scene: fire.draw(camera) every frame

An emitter draws nothing until startEmission() is called. By default it stops by itself after one second. Particles are small colored squares managed by the emitter (you never create one yourself): once emitted they live in camera space, so moving the emitter does not move particles that are already flying. A particle disappears when its lifetime is over or when it reaches an edge of the camera.

Methods

MethodDescription
new ParticleEmitter(x, y)Creates an emitter at the given position, with the default settings below.
startEmission(endCallback)Starts emitting. The optional callback is called with the emitter once emission is over and every particle is gone.
stopEmission()Stops emitting. Existing particles finish their life.
draw(camera, zOrder = 0)Queues the emitter on a camera for the current frame. Not needed if the emitter is in a Scene.
clone()Returns a new emitter with the same settings. Use it to have several bursts at the same time, since one emitter has a single running emission.

Properties

PropertyDefaultDescription
x, yconstructorWhere the particles are born.
emissionRate10Number of particles emitted per second.
particlesPerEmission1Number of particles created each time the emitter fires.
emissionDuration1Duration of the emission in seconds. 0 means unlimited. Reading the property returns milliseconds.
particleLifetime{min:1000, max:2000}Lifetime range in milliseconds, picked randomly for each particle.
particleSize{width:1, height:1}Size of a particle in pixels.
particleEmissionSpeed{min:1, max:3}Initial speed range, in pixels per frame.
particleEmitterAngleRange{rangeMin:45, rangeMax:90}Range of emission angles in degrees. 0 points right and 90 points down (screen coordinates). Use {rangeMin:0, rangeMax:360} for all directions.
particleEmitterDirection{x:0, y:-1}Vector added to the initial velocity of every particle. Use {x:0, y:0} for a neutral emitter.
particleAcceleration{x:0, y:0}Added to the velocity of each particle on every frame: gravity, wind…
particleColorRange{startColor:"#ffffff", endColor:"#000000"}Each particle gets a random color between the two. Use hex ("#ff4400") or "rgb(255, 68, 0)". Color names such as "blue" are not supported.
particleColorChangeRate{r:0, g:0, b:0}Amount added to each color channel on every frame (kept between 0 and 255), to make particles fade or change color.
isEmitting–Read-only boolean.

Several bursts: clone the emitter

While an emitter is running, calling startEmission() again would restart it. For effects that can overlap (impacts, explosions), clone a template, add the clone to the scene, and remove it when it is done:


const burst = burstTemplate.clone();
burst.x = 300;
burst.y = 200;
burst.startEmission((emitter) => scene.remove(emitter));
scene.add(burst, 1);
