Gadget

The base class of interface widgets such as Button. It draws a styled rectangle with an optional text, tracks the mouse, and fires events. Everything described here is available on every gadget.

Using a gadget

A gadget is drawn through a Scene, or with gadget.draw(camera, zOrder = 0) on every frame. Its position is in camera coordinates and its dimension is its size.


scene.add(gadget);
gadget.backgroundColor = "#4cc9f0";
gadget.borderRadius = [12];
gadget.hoverStyle = { backgroundColor: "#90e0ef" };
gadget.onClick = () => console.log("clicked");

Gadgets listen to the mouse through their camera: they react while camera.isMouseOver is true, within a margin of about 8 pixels around their rectangle. If several gadgets overlap, only the first one created receives the press and the click.

Mouse events

Assign a function to the property. Each property can hold one function.

PropertyCalled
onMouseEnter(camera)When the mouse enters the gadget.
onMouseLeave(camera)When the mouse leaves it.
onMouseOver(camera)On every frame while the mouse is over it.
onActived()When the mouse button is pressed on the gadget.
onClick()When the gadget is clicked. It receives no argument.
mouseOverRead-only boolean, true while the mouse is over the gadget.

Style

PropertyDescription
backgroundColorAny CSS color. "#fff" by default.
borderObject { lineWidth = 1, color, style = "solid" }, or null for no border. Without a color, the current background color is used.
borderRadiusAn array of pixels: [all], [top, bottom] or [topLeft, topRight, bottomLeft, bottomRight].
boxShadowOne shadow, as an object { offsetX, offsetY, color, blur, inset } or an array [offsetX, offsetY, color, blur, inset], or several shadows as an array of those. As in CSS, the first shadow is painted on top. An inset shadow is drawn inside the gadget, without blur.

Shadows make the drawn area larger than the gadget, but they are not part of its dimension and do not react to the mouse.

Hover and pressed styles

hoverStyle and activeStyle are style overrides. They are layered over the normal style while they apply, and removed automatically afterwards: there is nothing to restore in onMouseLeave.

LayerApplies when
normal stylealways
hoverStylethe mouse is over the gadget
activeStylethe mouse button is held down and the mouse is over the gadget (on top of hoverStyle)

gadget.hoverStyle  = { backgroundColor: "#90e0ef" };
gadget.activeStyle = { boxShadow: [3, 3, "rgba(0, 0, 0, 0.5)"] };   // pressed: smaller shadow
gadget.hoverStyle  = null;                                           // no hover style

An override can contain backgroundColor, border, borderRadius and boxShadow, in the same formats as above. Only the listed properties are overridden. Assigning a new hoverStyle or activeStyle replaces the previous one, it does not merge with it. Changes made to the normal style while the mouse is over the gadget (in onClick, for example) are kept after the mouse leaves.

Text

The text is a Text, so it supports the same effect markup. It is black by default. It starts at the top-left corner of the gadget; with textAlign = "center" it is centered both horizontally and vertically.

NameDescription
valueThe text, with optional effect markup.
fontCSS font, for example "28px sans-serif".
textAlign, textBaseline, textDirectionSame values as the Canvas properties.
addTextGradient(name, gradient)Registers a gradient for the ${grad(name) …} effect.
updateText()Forces the text effects to update after changing effect properties.

Other members

NameDescription
position, dimension{x, y} and {width, height}. Set the dimension at creation: the text is sized from it.
draw(camera, zOrder = 0)Queues the gadget on a camera for the current frame. Not needed if it is in a scene.
destroy()Stops the gadget from handling the mouse. Call it when you stop using a gadget, typically when you also remove it from its scene. Otherwise a gadget removed while the mouse is over it keeps receiving clicks.

Creating a custom gadget

Gadget is not exported by jsge.js. Import it from its file, with the same base URL as the engine so that both share one copy of the code. Extend it with extends Gadget: the constructor takes { position, dimension, value } (an empty value means no text). Gadget handles the drawing, the hit testing and the events; your class adds its own state and reacts to it through the public properties.

The example below is a toggle switch. Its normal style depends on its state, so the hover and pressed overrides, which only touch the border, work in both states.


import { Gadget } from "https://cdn.jsdelivr.net/gh/AubryBoulet/JSGE@main/JSGE/classes/gadget.js";

class Toggle extends Gadget {
  #label;
  #checked;
  onChange;                                   // optional callback(checked)

  constructor(label, position, checked = false) {
    super({ position, dimension: { width: 260, height: 50 }, value: "" });
    this.#label = label;
    this.#checked = checked;
    this.font = "22px sans-serif";
    this.textAlign = "center";
    this.borderRadius = [25];
    this.border = { lineWidth: 2, color: "#222" };
    this.hoverStyle = { border: { lineWidth: 4, color: "#222" } };
    this.activeStyle = { border: { lineWidth: 6, color: "#222" } };
    this.onClick = () => { this.checked = !this.#checked; };
    this.#refresh();
  }

  get checked() { return this.#checked; }
  set checked(value) {
    this.#checked = Boolean(value);
    this.#refresh();
    if (typeof this.onChange === "function") this.onChange(this.#checked);
  }

  #refresh() {
    this.backgroundColor = this.#checked ? "#95d5b2" : "#dee2e6";
    this.value = this.#label + ": " + (this.#checked ? "ON" : "OFF");
  }
}

Two instances of the toggle above. Hover and press them to see the style layers, and click to switch.
