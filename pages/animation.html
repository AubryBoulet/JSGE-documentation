Animation

Animated sprites are built from a sprite sheet: one image containing the frames of one or several animations, laid out in a grid.

The animation settings live in the sprite’s animations object. The class itself is not exported by jsge.js: you reach it through sprite.animations.

Usage


// 1. Load the sprite sheet with animate = true
const sheet = await Sprite.load("images/hero-sheet.png", true);

// 2. Describe the grid: 2 rows of 4 frames
sheet.animations.row = 2;
sheet.animations.column = 4;

// 3. Declare the animations: first frame, last frame, name, frameRate
sheet.animations.createAnimationFrames(0, 3, "idle", 10);
sheet.animations.createAnimationFrames(4, 7, "run", 5);

// 4. Choose the animation of each entity
const hero = Entity.create({ sprite: sheet, position: { x: 100, y: 100 } });
hero.currentAnimation = "idle";

Frames are numbered from 0, left to right then top to bottom. The size of a frame is computed from the image size and the row and column counts. Every entity using an animated sprite must have a currentAnimation before it is updated, otherwise an error is thrown. Each entity keeps its own copy of the animation state, so entities can share a sprite sheet while playing different animations or being on different frames.

Frame rate

The frameRate of an animation is the number of game frames each picture stays on screen. With a camera running at 60 FPS, frameRate = 6 plays 10 pictures per second. An entity can change its own speed with entity.frameRate = 3.

Methods and properties

NameDescription
row, columnNumber of rows and columns of the sprite sheet. Setting them recomputes the size of a frame.
frameWidth, frameHeightSize of a frame in pixels. Computed from the image and the grid, but you can set them.
createAnimationFrames(startFrame, endFrame, animationName, frameRate = 1, frameWidth, frameHeight)Declares an animation made of the frames from startFrame to endFrame (both included). The optional sizes override the default frame size for this animation.
setAnimationFrameHitBox(animationName, startWidth, endWidth, startHeight, endHeight)Sets the hit box of an animation, in pixels inside a frame. It is used for entity collisions and for landing on elements with gravity. The default hit box covers the whole frame.
getAnimationFrame(animationName)Returns a copy of the animation data (frames, frameRate, frameWidth, frameHeight, frameHitBox…). Throws an error for an unknown name. This is what entity.currentAnimation uses.
deleteAnimationFrames(animationName)Removes a declared animation.
imageThe sprite sheet image.

Hit boxes

A character is rarely as wide as its frame. Shrink the hit box so that collisions match the drawing:


// frames are 64x64, the character occupies x: 16..48 and y: 8..64
sheet.animations.setAnimationFrameHitBox("idle", 16, 48, 8, 64);
