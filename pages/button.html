Button

A clickable gadget with a ready-to-use look: grey, rounded, with a border, that darkens when hovered and when pressed.

Button is a Gadget: events, style, hover and pressed styles, text and the other members are all described on that page. This page only covers what is specific to buttons.

Usage


const button = Button.create("Play", { width: 200, height: 50 }, { x: 400, y: 300 });
button.onClick = () => startGame();

scene.add(button);         // or button.draw(camera) every frame

Button.create(value, dimension, position) takes the text, the size {width, height} and the position {x, y}, in camera coordinates. Buttons currently have a color background only.

Default look

PropertyDefault value
backgroundColor"lightGrey"
border{ color: "black" }
borderRadius[5]
hoverStyle{ backgroundColor: "darkGrey" }
activeStyle{ backgroundColor: "grey" }

Change any of them to restyle the button. Assigning a hoverStyle or an activeStyle replaces the default one, and null removes it.

Try it

The hover color and the smaller shadow of a pressed button come from hoverStyle and activeStyle: no code is needed to restore the look when the mouse leaves or the button is released. The click changes the text, which is a lasting change.
