Button

A clickable rectangle with a text, a background, a border, rounded corners and shadows. It reacts to the mouse.

Buttons are built on the Gadget class, which provides everything described below (drawing, styling, mouse events). Gadget is not exported by jsge.js: use Button. Buttons currently have a color background only.

Usage


const button = Button.create("Play", { width: 200, height: 50 }, { x: 400, y: 300 });
button.font = "28px sans-serif";
button.backgroundColor = "#4cc9f0";
button.borderRadius = [12];
button.onClick = () => startGame();

scene.add(button);         // or button.draw(camera) every frame

Button.create(value, dimension, position) takes the text, the size {width, height} and the position {x, y} (in camera coordinates). Like other drawable objects, a button is drawn through a Scene, or with button.draw(camera, zOrder = 0).

Mouse events

PropertyCalled
onClickWhen the button is clicked.
onMouseEnter(camera)When the mouse enters the button.
onMouseLeave(camera)When the mouse leaves it.
onMouseOver(camera)On every frame while the mouse is over it.
mouseOverRead-only boolean, true while the mouse is over the button.

The mouse is tracked in page coordinates, with a few pixels of margin around the button, and only while it is over the camera that draws it. As for cameraMousePosition, the canvas should sit at the top-left of the page, without CSS scaling.

Style

PropertyDescription
position, dimension{x, y} and {width, height}.
backgroundColorAny CSS color. White by default.
borderObject { lineWidth = 1, color, style = "solid" }.
borderRadiusAn array: [all], [top, bottom] or [topLeft, topRight, bottomLeft, bottomRight], in pixels.
boxShadowA shadow object { offsetX, offsetY, color, blur, inset }, the same as an array [offsetX, offsetY, color, blur, inset], or an array of several shadows.

Text

The text is a Text: it supports the same effect markup (colors, wave, shake, blink, gradients). It is black by default, use ${white …} markup to color it.

NameDescription
valueThe text, with optional effect markup.
fontCSS font, for example "28px sans-serif".
textAlign, textBaseline, textDirectionSame values as the Canvas properties.
addTextGradient(name, gradient)Registers a gradient for the ${grad(name) …} effect.
updateText()Forces the text effects to update, useful after changing effect properties.

Try it

Hover the button to change its color, and click it to change its text.
