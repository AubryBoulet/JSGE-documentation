Transition

Smoothly animates a number from one value to another, using an easing function. Perfect for movements, fades, scaling or any value that should not just jump.

Usage

Transition.create() takes a single array and returns the id of the transition. Your callback receives the current value on every frame.


const id = Transition.create([
  0,                          // initial value
  500,                        // target value
  "easeOutBounce",            // timing function (default "linear")
  (value) => { box.position.x = value; },   // called on every frame
  2,                          // duration in seconds (default 1)
  0.5,                        // delay in seconds (default 0)
  () => { box.position.x = 500; }           // optional: called when finished
]);

Transitions run on their own animation loop, independently from cameras. The loop sleeps when no transition is running. Setting the exact final value in the end callback is a good habit, as the last frame can land slightly past the target.

Array items

#ItemDefaultDescription
1initial value–Starting number.
2target value–Final number.
3timing function"linear"The name of an easing function (see below) or a custom function (t, b, c, d) => value where t is the elapsed time and d the duration in milliseconds, b the initial value and c the change in value (target − initial).
4callbacknoneCalled with the current value on every frame.
5duration1In seconds.
6delay0In seconds, before the transition starts.
7end callbacknoneCalled once, when the transition is over.

Static methods

MethodDescription
Transition.create(array)Starts a transition and returns its id. An unknown easing name throws an error.
Transition.delete(id)Cancels one transition.
Transition.clear()Cancels every transition.
Transition.reset(id)Restarts a transition from the beginning (the delay applies again).

Easing functions

"linear", plus the three variants easeIn…, easeOut… and easeInOut… of each of these families:

QuadCubicQuartQuintSineExpoCircElasticBackBounce

For example "easeOutQuad", "easeInOutCubic" or "easeOutBounce".
